# 마이페이지 문서

## 개요

마이페이지는 현재 로그인 사용자의 기본정보와 비밀번호를 관리하는 화면입니다.

## 주요 기능

- 내 정보 조회
- 기본 정보 수정
- 비밀번호 변경

## 주요 API

- `/mypage/main.do`
- `/mypage/detail.json`
- `/mypage/save.json`
- `/mypage/changePassword.json`

## 이력

- 정보 수정: `MYPAGE_UPDATE`
- 비밀번호 변경: `MYPAGE_PASSWORD_CHANGE`

위 코드는 접속 이력에 저장됩니다.
