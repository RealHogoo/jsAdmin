# 공통 코드 관리 문서

## 개요

공통 코드 관리는 화면 전반에서 사용하는 코드값을 조회하고 유지하는 기능입니다.

## 주요 기능

- 코드 목록 조회
- 코드 등록/수정
- 코드 삭제
- 검색어 기반 필터링

## 주요 API

- `/code/main.do`
- `/code/list.json`
- `/code/save.json`
- `/code/delete.json`

## 화면 규칙

- 그리드 첫 열은 `No.` 순번
- 헤더는 한글 기준으로 표시
- 목록은 공통 chunk loader 규칙 사용

## 비고

- 코드 그룹과 코드 항목을 화면 정책에 맞게 확장할 수 있습니다.
