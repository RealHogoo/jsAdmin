# 타임라인 관리 문서

## 개요

타임라인은 운영 이벤트나 게시형 이력을 시간순으로 관리하는 화면입니다.

## 주요 기능

- 목록 조회
- 상세 조회
- 등록/수정
- 삭제
- 홈 화면 요약 연동

## 주요 API

- `/timeline/home.do`
- `/timeline/main.do`
- `/timeline/list.json`
- `/timeline/detail.json`
- `/timeline/save.json`
- `/timeline/delete.json`

## 비고

- 타임라인 목록과 상세는 비로그인 공개 정책으로 운영할 수 있습니다.
