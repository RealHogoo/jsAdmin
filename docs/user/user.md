# 사용자 관리 문서

## 개요

사용자 관리 기능은 관리자 계정의 생성, 수정, 비활성화, 잠금 해제, 비밀번호 초기화를 담당합니다.

## 주요 기능

- 사용자 목록 조회
- 사용자 상세 조회
- 사용자 등록 및 수정
- 계정 비활성화
- 잠금 해제
- 임시 비밀번호 기반 비밀번호 초기화

## 주요 API

- `/user/main.do`
- `/user/list.json`
- `/user/detail.json`
- `/user/save.json`
- `/user/delete.json`
- `/user/unlock.json`
- `/user/resetPassword.json`

## 관련 테이블

- `ADM_USER_MST`
