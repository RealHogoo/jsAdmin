# 메인/대시보드 문서

## 개요

메인 화면은 관리자 포털의 기본 진입점입니다.

- URL: `/home.do`
- 초기 부트 경로: `/main.do` -> `/home.do`

## 역할

- 로그인 후 기본 랜딩 화면 제공
- 공지사항, 타임라인, 상태 요약 진입점 역할
- 좌측 메뉴 트리와 함께 관리자 내비게이션 제공

## 비로그인 정책

현재 일부 공개 데이터는 비로그인 상태에서도 접근 가능합니다.

- `/menu/tree.json`
- `/notice/list.json`
- `/timeline/list.json`
- `/timeline/detail.json`

즉, 로그아웃 상태에서도 좌측 트리와 대시보드/타임라인 일부 콘텐츠는 표시될 수 있습니다.

## 헤더 동작

헤더 로그인 상태는 로컬스토리지 값만 보지 않고 `/auth/ping.json`으로 재검증합니다.

## 좌측 메뉴

좌측 메뉴는 `ADM_MENU_MST` 기반 트리 구조이며, 저장된 아이콘 값이 메뉴명 앞에 표시됩니다.

## 관련 화면

- 공지사항
- 타임라인
- 헬스체크
- 각 운영 관리 메뉴 진입
