# 메뉴 관리 문서

## 개요

메뉴 관리는 관리자 좌측 메뉴 트리와 각 화면 진입 구조를 관리합니다.

## 주요 기능

- 메뉴 트리 조회
- 메뉴 등록/수정
- 메뉴 완전 삭제
- 사용 여부 조회
- 메뉴 아이콘 선택

## 현재 동작

### 메뉴 트리

- `ADM_MENU_MST` 기준 계층형 구성
- `UP_MENU_SEQ` 기준 부모/자식 구조
- `SORT_ORD` 기준 정렬

### 삭제

현재 삭제는 `USE_YN='N'` 논리 삭제가 아니라 **실제 삭제**입니다.

- 선택 메뉴 삭제
- 하위 메뉴 트리 삭제
- 연관 권한 매핑 정리

### 아이콘

- 메뉴 아이콘 입력 옆 선택 버튼 제공
- Material Symbols 아이콘 선택 모달 제공
- 선택한 아이콘은 좌측 메뉴 트리에 표시

## 주요 API

- `/menu/tree.json`
- `/menu/list.json`
- `/menu/detail.json`
- `/menu/save.json`
- `/menu/delete.json`

## 화면 규칙

- 검색 조건과 버튼은 상단 툴바에 배치
- 목록은 공통 그리드 규칙 사용
- `No.` 컬럼은 화면 표시용 순번이며 DB 시퀀스를 직접 노출하지 않음

## 관련 테이블

- `ADM_MENU_MST`
- `ADM_AUTH_MENU`
- `ADM_AUTH_USER`
